# Revolut Portfolio Widget

A read-only desktop tracker for crypto holdings you enter manually. No Revolut login or API key is required.

## Quick install for Windows 10/11 x64

1. Download the [Windows ZIP](https://github.com/madebybliss/Revolut-Portfolio-Widget-Releases/releases/latest/download/RevolutPortfolio-Windows-x64.zip).
2. Right-click the ZIP and choose **Extract All**. Use a folder you can write to so the widget can install future updates.
3. Open the extracted folder and double-click `RevolutPortfolio.exe`.

## Quick install for Linux amd64

1. Download the [Linux archive](https://github.com/madebybliss/Revolut-Portfolio-Widget-Releases/releases/latest/download/RevolutPortfolio-Linux-amd64.tar.gz) and extract it.
2. Open a terminal in the extracted folder and run:

   ```sh
   sudo apt install ./revolut-portfolio_*_amd64.deb
   revolut-portfolio
   ```

   On Ubuntu, Debian, or Linux Mint, you can also launch **Revolut Portfolio Widget** from the application menu after installing it. To run the portable version from the extracted folder, use `./RevolutPortfolio`.

On either platform, open **Settings** to enter your holdings. The [full README](https://github.com/madebybliss/Revolut-Portfolio-Widget-Releases/releases/latest/download/README.md) covers supported Linux versions, updates, and antivirus alerts.
